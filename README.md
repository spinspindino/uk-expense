# 英鎊記帳

在 iPhone 上記英國生活開支的小 app（PWA：用 Safari 開網址，再「分享 → 加入主畫面」）。

- 只記英鎊，不換算台幣。
- 資料只存在手機本身的瀏覽器裡，不會上傳；右上角 CSV 按鈕匯出正在看的那個月（檔名如 2026-10.csv，可用 Numbers 開），設定裡的「匯出全部紀錄」當完整備份。
- 「記帳」分頁：每月收支、預算進度、類別統計、每日明細。「總覽」分頁：目前現金、可支應月數、本月預算。
- 現金 = 設定的某天餘額 ＋ 之後的收入 － 之後的支出；重新對帳只要再輸入一次新餘額，不會改動過去紀錄。
- 類別、付款方式沿用「英鎊開支追蹤」表；創作材料器材、工作室/場地、展覽/報名費、軟體訂閱預設算業務成本。

## 檔案在做什麼

| 檔案 | 用途 |
|---|---|
| `index.html` | 畫面的骨架：有哪些區塊、按鈕、輸入欄 |
| `style.css` | 外觀：套用 Street Alchemist 設計系統（Night 主題）的顏色、字體、間距 |
| `app.js` | 動作：新增、編輯、刪除、加總、匯出 |
| `manifest.webmanifest` | 告訴手機這是 app：名稱、圖示、全螢幕開啟 |
| `sw.js` | Service worker：讓沒網路時也能開 |
| `icons/` | 主畫面圖示 |
